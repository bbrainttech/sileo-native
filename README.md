# sileo-native

An opinionated, physics-based toast library for React Native and Expo. A native port of sileo.

## Installation


```sh
npm install sileo-native
```


## Usage


```js
import { multiply } from 'sileo-native';

// ...

const result = multiply(3, 7);
```
